Place your hero background video here as:

  hero-video.mp4

Requirements / recommendations:
- Format: MP4 (H.264 codec) for best browser compatibility.
- Keep the file optimized (ideally under 5-8 MB) for fast page loads.
- Landscape orientation, 16:9, at least 1920x1080 recommended.
- No audio is required — the video plays muted automatically.

No code changes are needed. Once "hero-video.mp4" is placed in this folder,
it will automatically appear as the Hero section's background video with:
  - autoplay, muted, loop, playsinline
  - full-cover responsive sizing
  - a dark overlay for text readability
  - automatic fallback to the existing gradient/image background if the
    file is missing or fails to load.
